Black Friday Sales Analysis
A data analysis project exploring customer purchasing behavior during Black Friday sales.

Motivation
Understanding customer purchasing patterns during Black Friday can help retailers tailor marketing strategies, optimize inventory, and maximize sales. This project aims to analyze the Black Friday sales dataset to uncover trends and actionable insights.

Data Source
Dataset: Black Friday Sales Data

Contains over 500,000 transactions with features such as User_ID, Product_ID, Gender, Age, Occupation, City_Category, Stay_In_Current_City_Years, Marital_Status, Product_Category_1/2/3, and Purchase amount.

Methodology
Data Cleaning: Handled missing values and formatted categorical variables.

Exploratory Data Analysis (EDA): Analyzed demographic distributions, purchase trends, and product category performance using Python (pandas, matplotlib, seaborn).

Visualization: Created bar plots, histograms, and heatmaps to illustrate key findings.

Feature Engineering: Combined features (e.g., MaritalGender) to enhance analysis.

Insights: Identified top spending age groups, gender-based purchasing trends, and high-performing product categories.

Results
Males made more purchases than females.

The 26-35 age group was the most active in terms of purchases.

Product Category 1 was the most popular among all categories.

City category and years in current city influenced purchasing patterns.
